Preguntas frecuentes

Preguntas frecuentes sobre PropLync

¿Necesito ser agencia para usar el generador?

No, para una sola propiedad no. El generador funciona sin cuenta en /generate. Para gestionar varias propiedades, leads y publicar desde un panel, se necesita una cuenta de agencia.

¿Puedo publicar directo a Instagram?

Si, para el formato de post via la API oficial de Meta (Instagram Graph API) — sin descargar y volver a subir. Los demas formatos (carrusel, story, video, etc.) se descargan para publicarlos manualmente.

¿De donde salen las fotos?

Si subes tu propia foto, se usa esa. Si no, el sistema busca automaticamente una fotografia real y con licencia que combine con tu propiedad.

¿Que pasa con mis datos y los de mis clientes?

PropLync esta pensado para cumplir con la LFPDPPP desde el diseno. La direccion exacta se mantiene interna: las piezas publicas muestran zona o colonia. Los datos personales solo se usan con una finalidad definida. Y solo se usan fotos propias o autorizadas por la agencia.

¿Cuanto cuesta?

Depende del alcance real de tu operacion. Lo definimos juntos en un diagnostico corto, sin compromiso.

¿La locucion del video tiene costo?

Una voz local (generada en tu equipo) es gratuita. Si prefieres una voz profesional por API (ElevenLabs, etc.), se paga por uso — generalmente centavos por video.
